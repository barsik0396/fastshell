## 🤔 What is fastshell?

fastshell is very fast, stable, secure and small shell written on C and C++.

## 🚀 Installation

### 🐧 On Linux
1. Download package from [**Releases** page](https://github.com/barsik0396/fastshell/releases)
2. Open it
3. Install
4. Done; you can execute `fastshell` in your terminal!

### 🍎 On macOS

> No official fastshell binaries for macOS.
